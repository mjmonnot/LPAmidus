# LPAmidus

Research project examining personality profiles and work-related outcomes using
public MIDUS (Midlife in the United States) survey data.

## Status

This repository is a **placeholder** for an ongoing study. Analysis code, data
products, and results are maintained locally and are **not published** here at
this time.

## Data

MIDUS data are obtained from ICPSR under their terms of use. This repository does
not distribute MIDUS files.
