# Software environment (high level)

As reported in the preprint Method. Exact package versions for a full replication package will be released with a later code deposit or provided on request.

| Component | Role |
|---|---|
| R | Data preparation, measurement checks, enumeration support |
| Python | Selected derived constructs (e.g., cognitive composites) and figure utilities |
| Latent Markov / LPA estimation | Maximum-likelihood latent profile and latent transition models (see Method for implementation) |
| Mplus | Cross-software confirmation of selected solutions (see Method) |

This repository does **not** currently ship analysis scripts or session lockfiles.
